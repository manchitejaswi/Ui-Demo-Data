# Push to vulnerability-dashboard Branch

To push this code to the `vulnerability-dashboard` branch, run the following commands:

```bash
cd security-dashboard
git checkout -b vulnerability-dashboard
git push origin vulnerability-dashboard
```

Alternatively, if you want to push from the root directory:

```bash
git checkout vulnerability-dashboard
git merge copilot/create-security-vulnerability-dashboard
git push origin vulnerability-dashboard
```

The vulnerability-dashboard branch has been created and all code has been committed locally.
